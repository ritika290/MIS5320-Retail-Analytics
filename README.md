# MIS5320-Retail-Analytics
Retail Sales and Inventory Analytics Decision Support System
Project Overview
This project develops a Power BI decision support system for analysing retail sales, profitability, inventory availability and future demand using the Maven Toys dataset.
Course
MIS5320 – Applied IS Project
Part B – Week 3
Project Objectives
- Analyse retail sales and profitability.
- Identify high-performing products and store locations.
- Monitor inventory levels and stock shortages.
- Forecast future retail demand.
- Support business decisions through interactive dashboards.
Technologies Used

Microsoft Power BI Desktop, Power Query, DAX, CSV datasets and GitHub.

Dataset
- 829,262 sales records
- 35 products
- 50 retail stores
- 638 calendar dates
Implemented Dashboards
1. Executive Overview
2. Sales Performance Analysis
3. Inventory Analysis
4. Demand Forecasting
Current Progress
- Data cleaning and transformation completed.
- Five active data model relationships established.
- Twelve DAX measures implemented.
- Four interactive dashboards developed.
- Initial functional testing completed.
- Forecast configured for 30 daily points with a 95% confidence interval.
Project Status
Week 3 MVP implemented. Further validation, documentation and team collaboration are in progress.
